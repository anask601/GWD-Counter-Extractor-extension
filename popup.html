🔍 How to Use

1Open GWD Page

Navigate to your Google Web Designer project page (preview.html or index.html)

2Copy Index URL (Optional)

If on preview.html, click "📋 Copy Index URL" to get the index.html URL, then navigate manually

3Extract Counters

Click "🔍 Extract Counters" for counter elements or "🎬 Analyze Videos" for video information

4Copy Results

Use "📋 Copy" to copy both counters

💡 Tips

  • ⚠️ Yellow warnings indicate NaN values that may cause tracking issues
  • 🎬 Video analysis extracts URLs and durations from video/source elements
  • 🔗 Copy Index URL converts preview.html to index.html automatically
  • 📱 Extension works on any localhost port
  • ⌨️ Keyboard shortcut: Ctrl+Shift+V for video analysis
